# Changelog

本文件记录 TRIZ 职工创新研究 Skill 的公开发布版本。版本号遵循语义化版本（semver）。

## [2.2.0] - 2026-09-01

### 修复（发布阻断）

- 阶段编号统一为七状态 `G0 → G1 → G1.5 → G2 → G3 → G4 → G5`：`research-workflow.md` 不再使用第二套 G0—G8 编号；原 G5—G7 改为 G4 内部验证成熟度 `V0—V3`，原 G8 折入 G5；正文小节 0—13 建立单向映射。
- 清除公开包内全部具体项目案例词（对象、结构、工序、口径）；案例材料只保留在项目工作区，不进入 Skill 或公开仓库。
- 恢复矩阵回归锚点：固定回归单元恢复为 16 个（历史转录差异 6 + 源格式清理 4 + 行列方向镜像 2 + 高频场景 4），并输出 `golden_cells` 计数供双运行时比对。矩阵载荷及 SHA-256 保持不变。
- `deep-research-protocol.md` 9.1/9.2 顺序修复（主张—证据—论证桥在前），并补充目录。
- `validate_skill.py` 重写：版本号从 `SKILL.md` frontmatter 读取，不再硬编码；矩阵自检一律走子进程，不再产生 `scripts/__pycache__`；新增发布清单校验（未列入清单的文件判失败）、通用内容合规扫描（命中判失败）、占位符扫描、CHANGELOG 版本一致性检查。

### 新增（普通模型稳定执行）

- `SKILL.md` 顶层执行契约压缩为 10 条；阶段细节下放到对应 reference。
- 新增 `references/intake-guide.md`：大白话信息采集，先抽取已知信息、后补问，最多 1—3 个会改变对象、安全或目标的关键问题。
- G1.5 确认门改为白话确认卡：现场话复述 + 矛盾白话 + 编号方向 + 回复选项；用户沉默仍不视为授权。
- 研究台账与会话检查点字段统一；新增阶段播报、暂停/恢复协议；任何现场否决回灌为 F/约束并做影响分析。

### 新增（确定性与无脚本能力）

- 新增 `references/parameter-guidance.json`：39 参数的现场常见说法、可测量量、易混参数和区分判据；矩阵 JSON 保持纯净事实源不变。
- Python/Node 查询器同步新增 `--search`（按现场说法返回候选参数）、`--explain`（解释参数定义和易混邻居）、`--version`、内联 `--batch` 批量查询；错误信息统一为“问题—给定值—修复建议”。
- 新增 `references/matrix-rows/R01.md … R39.md` 行分片，由矩阵 JSON 自动生成并校验哈希；无 Python/Node 的平台只读取目标行分片即可完成确定性查询，不再加载完整矩阵。
- `validate_skill.py` 校验行分片与矩阵载荷一致。

### 新增（成果传播与开源体验）

- 新增可选一页纸成果速览模板（班组汇报/申报/展板场景，不替代决策摘要）。
- 新增图示类型选择表：流程/因果用 Mermaid，机理/几何用 SVG，Word/PPT 优先原生可编辑图形，ASCII 仅兜底。
- README 增加 5 分钟上手、常见问题和其他平台安装与验证方法。
- 删除未使用的 hero-v1 横幅，hero-v2 做保守调色板压缩（256 色），已做视觉检查确认清晰可辨。
- `agents/openai.yaml` 同步中文入口与默认提示。

### 修复（发布前审核回归）

- 验证成熟度全包统一为唯一一套 `V0—V3`（V0 概念证据 / V1 代表性短样 / V2 完整流程 / V3 受控现场）：`engineering-claim-safety-checks.md`、`output-templates.md` 原 `V0—V4` 定义及冲突编号含义已全部替换；校验器新增全包扫描，出现第四级成熟度编号或区间表述即判失败。
- 确定性查询路径贯穿全部执行清单：`triz-analysis-output.md`、`weak-model-playbook.md`、`matrix-usage.md`、`research-workflow.md`、`standalone-capability-map.md` 统一为"Python / Node / `Rxx.md` 行分片三选一"，通过清单接受行分片并要求反向单元复核；校验器新增"只允许脚本"措辞回归扫描。
- README 5 分钟示例修正为真实查询结果：欲改善 `#10 力（强度）`、随之恶化 `#12 形状`，`R10×C12` 返回原理 #10 预先作用、#35 参数变化、#40 复合材料、#34 抛弃与再生；该示例已纳入校验器黄金测试（用矩阵本体复算）。
- 公共校验器不再硬编码任何具体项目案例词，只保留通用规则（内部案例引用、本机绝对路径）；具体案例词扫描移到项目工作区的私有发布前 QA 脚本。
- Python/Node 错误路径统一：`--explain abc`、`--format xml`、未知参数、缺少参数值、编号越界等场景的 stdout、stderr、退出码逐字一致；校验器改为表驱动回归，覆盖单查、批查、搜索、解释、空单元、对角线和错误路径共 18 个用例。
- README 修正三处表述：交付层级默认 standard（不因问题大小自动降档）；Windows PowerShell 安装命令单列可直接执行；项目数据隐私改为"本技能不主动持久化，会话数据政策取决于所用平台与单位规定"。
- `agents/openai.yaml` 元数据合规：简介压缩至 64 字符内，默认提示改为一句启动语。
- 普通模型上下文改为按阶段分片装载（G0 只读入口与采集指南，后续阶段按需加载）。
- 校验报告修正：合法行分片不再列入 `manifest.unexpected`，另设 `generated_row_shards` 计数。

### 兼容性

- `contradiction-matrix.json` 载荷与 SHA-256 完全不变；查询方向、输出格式和退出码语义与 2.1.0 保持一致（新增子命令为增量功能）。

# 最小可审计输出模板 v2.1

模板是最低字段，不要求每个案例机械生成同样数量的文档。保持版本号、日期和证据状态。

## 1. 研究台账

| 字段 | 内容 |
|---|---|
| 研究目标 | 预期交付和决策用途 |
| 原始问题 | 用户原述，不替换口径 |
| 已确认修正 | 修正内容、日期、来源 |
| 当前阶段 | 阶段、证据模式、允许/禁止动作 |
| 事实 F | 现场已知信息 |
| 实测 M | 方法、样本、结果、原始记录 |
| 来源 S | 命题、来源、日期、边界 |
| 假设 H | 推翻条件和验证编号 |
| 决策日志 | 选择、理由、反对证据 |
| 流程改进 | 触发证据、旧规则、新规则 |

## 3.1 TRIZ 完整方向确认稿

首次 TRIZ 输出不能只有上表。按 [triz-analysis-output.md](triz-analysis-output.md) 依次给出：

1. 对象结构与工艺特性（已知/典型情景/未知分开）；
2. 完整工序流及每节点失效；
3. 3～6 个核心工程瓶颈；
4. 系统边界、功能/因果模型、IFR 和资源；
5. 主次技术矛盾的 EC1/EC2、参数映射和逐单元查表；
6. 物理矛盾的相反要求与分离策略；
7. 物—场模型、问题类型、标准解候选和编号依据；
8. 演化/裁剪方向及适用条件；
9. 候选作用机制和系统架构；
10. “瓶颈—TRIZ 工具—参数/模型—原理/标准解—方案—证据—反证”汇总表；
11. 当前不能声称的效果、关键风险和最低成本验证；
12. 用户方向确认问题，并在收到明确回复前暂停深研。

### 加权评分

| 指标 | 定义 | 权重 | 0 分锚点 | 1 分锚点 | 3 分锚点 | 5 分锚点 | 未知规则 |
|---|---|---:|---|---|---|---|---|

## 10. 效益模型

至少记录：完整时间、准备分摊、一次合格率、返工、清理、维护、端数、临界批量、是否关键路径。无 M 数据时保留公式和空表，不填假设为“结果”。

## 11. 阶段结论（技术证据附件/内部决策记录）

1. **结论级别：** 概念研究 / 代理评价 / 机理验证 / 样机 / 模拟现场 / 获批现场。
2. **条件性推荐：** 主路线、工程后备、成熟基准、超系统替代。
3. **核心追溯：** 主矛盾参数对、矩阵原理、关键作用机制。
4. **最强证据：** 支持与反对各至少一项。
5. **当前允许：** 下一阶段可执行事项。
6. **当前边界：** 不能声称或实施的事项；不要把本项大段复制进决策摘要。
7. **下一试验：** 最低成本、能改变决策的验证。
8. **退出条件：** 何时停止自研、切换后备或采购。
9. **研究透明度：** 如交付规范需要，在技术证据附件说明 AI 辅助范围和责任复核，不单列为摘要章节。

# 工程命题与安全硬闸门 v2.1

本文件用于阻止普通模型把“相似、可能、未检得、厂家宣称、类比机理或人工手感”升级成工程事实。它必须在 G0 身份锚定、G2 证据综合、G3 方案选择和 G5 最终复核各执行一次。

## 1. 七道硬闸门

对所有会改变结构、尺寸、安全、采购、制造、试验或专利决策的命题，依次回答：

1. `I 身份`：目标对象的型号、版本、批次和结构已经由什么直接证据确认？
2. `E 证据`：来源身份、权威性、直接性、独立性和时效性分别怎样？
3. `A 适配`：来源的对象、材料、尺度、边界和工况是否与目标一致？
4. `T 迁移`：如果是类比，哪些机理能迁移，哪些差异可能使其失效？
5. `S 安全`：是否把未经验证的材料、摩擦、人工感觉或控制逻辑当成保护屏障？
6. `P 专利`：是否把技术检索越界写成可专利、无侵权或 FTO 结论？
7. `V 验证`：样本、最不利条件、检测、通过/停止/升级规则是否互相一致？

任一项答案为“未知”时，命题必须降为 `H`，同时给出验证动作；任一项为“否”时，不得让该命题支持制造、现场试用或定型推荐。

## 2. I：对象与标识身份门

### 2.1 冻结规则

- 首次出现的型号、物料号、标准号、软件/图纸版本、单位和口径逐字复制到“原始标识”列；
- 不修正全半角、连字符、字母顺序、前后缀或疑似错字；
- 可以另建“候选规范名/别名”列，但不得覆盖原文；
- 只有目标对象的铭牌、合格证、采购/设计文件、原厂对应数据表或受控实物核验能够把候选身份升级为确认身份；
- 经销商、搜索共现、相邻型号、命名习惯只能形成身份假设。

### 2.2 身份假设表

| 原始标识 | 候选解释 | 支持证据 | 反对/冲突 | 当前状态 | 能否据此冻结结构 | 下一验证 |
|---|---|---|---|---|---|---|
| 逐字原文 | 正式型号/项目简称/录入错误等 | 来源 ID | 差异字符、结构或版本 | F/S/H | 是/否 | 铭牌、图纸、原厂或实物 |

### 2.3 阻断条件

若身份差异会改变材料、层序、尺寸、额定条件、保护功能、接口或安全方法，身份未确认前：

- 不得生成定型尺寸和制造图；
- 不得声称某产品“覆盖目标范围”或“适配该型号”；
- 只能用多个代理情景和最不利包络做概念分析；
- 报告首页显示“对象身份未冻结”。

## 3. E：来源五维核验

“页面已打开”只证明载体存在，不等于内容权威、直接支持或结论已核实。每个关键来源分别记录：

| 维度 | 问题 | 可用状态 |
|---|---|---|
| 身份/存在性 | 标题、作者/机构、日期、版本、编号和载体能否对应？ | V/P/L/X |
| 权威性 | 该机构是否有资格陈述这类事实？ | A/B/C/D |
| 直接性 | 原文是否直接支持当前命题，而非支持相邻命题？ | 直接/间接/不支持 |
| 独立性 | 是否为厂家自证、申请人自述、转载或独立评价？ | 独立/相关方/转载 |
| 时效性 | 版本/法律状态/产品状态在研究截止日是否仍适用？ | 当前/待确认/过期 |

来源总等级不能掩盖这五项。厂家对自家型号和标称规格可以是直接来源，但对跨场景效果、安全和优越性通常不是独立证据；采购聚合页、经销商和标准转载页不得因“看起来正式”自动评为 A。

### 3.1 来源核验最小字段

来源 ID、稳定 URL/文件、完整标题、作者/机构、发布日期或版本、访问日期、唯一编号、页码/权利要求/段落定位、支持命题的短摘录或忠实转述、五维状态、利益关系、冲突和使用边界。

缺少定位与原文支持时只能作线索，不能作关键工程结论的主证据。

## 4. 可复现检索与“未检得”规则

### 4.1 原始日志硬条件

每一条被计入“检索数量”的记录必须保留：日期、入口/数据库、未经改写的原始查询式、语言/地域/年份/分类过滤、可见命中范围、纳入/排除及理由、来源 ID、对应命题、失败或无结果状态。

- 只有主题词清单，没有逐条查询式：不得声称“完成 N 组检索”；
- 只有来源列表，没有排除记录：不得声称系统性或饱和；
- 只打开页面未核对身份：不得记为核验完成；
- 搜索摘要只能发现来源，不得替代原文。

### 4.2 缺失证据阶梯

| 等级 | 已完成工作 | 允许措辞 |
|---|---|---|
| N0 | 单次普通搜索 | “初步搜索未看到，不能据此判断” |
| N1 | 多组同义词、两种语言、明确时间范围 | “在所列普通搜索范围内未检得” |
| N2 | 专业数据库/分类号/引用追踪、重复项和排除记录 | “截至日期，在所列数据库与查询式范围内未检得” |
| N3 | 多数据库、多语言、相邻分类、反向引用并出现新增结果趋零 | “检索趋于饱和，但不证明绝对不存在” |

任何等级都不得直接写“市场没有”“国内空白”“世界首创”或“已确认不存在”。必须列出未覆盖的数据库、语言、时间、非公开产品、商业秘密和法律状态不确定性。

## 5. A：产品与方案适配门

来源证明产品标称范围，不等于证明目标适配。必须逐项比较：

| 适配维度 | 来源对象 | 目标对象 | 相同/不同/未知 | 差异后果 | 验证 |
|---|---|---|---|---|---|
| 对象身份/批次 |  |  |  |  |  |
| 几何范围与容差 |  |  |  |  |  |
| 材料、硬度、层序 |  |  |  |  |  |
| 保护/保留功能 |  |  |  |  |  |
| 环境、姿态、空间 |  |  |  |  |  |
| 完整动作与节拍口径 |  |  |  |  |  |
| 操作者、部署和维护 |  |  |  |  |  |

任一关键项未知时，正确结论是“候选基准/待样件适配”，不是“覆盖目标”“可直接使用”或“通过硬门槛”。

## 6. T：类比迁移卡

论文、专利或其他行业案例支持的是其原对象和边界。迁移到目标前必须填：

| 维度 | 原研究/产品 | 目标场景 | 可迁移判断 | 失效风险 | 最小试验 |
|---|---|---|---|---|---|
| 功能目的 |  |  |  |  |  |
| 结构拓扑 |  |  |  |  |  |
| 材料与表面 |  |  |  |  |  |
| 尺度与厚度 |  |  |  |  |  |
| 初始/边界约束 |  |  |  |  |  |
| 摩擦、粘结、预紧 |  |  |  |  |  |
| 载荷、速度、循环 |  |  |  |  |  |
| 制造与老化状态 |  |  |  |  |  |
| 安全与法规 |  |  |  |  |  |

只要关键边界不同，允许结论最多是“该来源支持候选机理存在”；不得写成“已证明目标方案可行”。先做能快速推翻迁移假设的试验。

## 7. S：安全屏障真实性检查

### 7.1 不得默认成为安全件的对象

以下内容没有验证和独立保护时，不能称为止挡、保护、联锁、保险或失效安全：

- 被加工对象自身的一层材料；
- 薄膜、箔、编织物、涂层、绝缘层或粘结层；
- 摩擦、自锁、弹性回弹、刀具“手感”和操作者经验；
- 软件判断、单一传感器或失电后状态未知的执行器；
- 厂家未覆盖目标工况的保护声明。

### 7.2 每个声称的屏障必须回答

1. 危险能量和失效链是什么？
2. 屏障是独立于被保护对象的结构吗？
3. 最坏公差、偏心、磨损、污染、误装、误操作和能源故障下是否仍有效？
4. 单点失效会不会直接造成伤害？
5. 如何检测屏障存在且功能正常？
6. 有什么破坏性/最不利试验证明其能力？
7. 残余风险和禁止用途是什么？

答不全时，将其改写为“待验证的作用机制”，并补独立限位、限力、隔离、护罩或失效回退。任何人身伤害或对象不可逆损伤风险均为硬门槛，不能被效率或经济分抵消。

## 8. P：专利与法律边界

通用研究模型可以做：现有技术检索、专利族发现、独立权利要求特征拆解、候选方案相同/不同特征表、法律状态线索和需专业复核的问题清单。

通用研究模型不得独立下结论：

- “具备新颖性/创造性/可授权”；
- “不侵权、FTO 通过、可自由实施”；
- “内部使用、非销售或研究用途当然不受约束”；
- “有结构差异所以避开全部权利要求”；
- “国内仍有专利空间”或“无专利障碍”。

正确措辞是：“在本次日期、数据库、同族和法律状态核验范围内，发现以下最近现有技术及潜在重叠；正式可专利性/FTO/实施判断需由有资质专业人员结合司法辖区和最新法律状态完成。”

硬门槛中的 IP 项只允许三种状态：`未发现明确完全覆盖的线索`、`存在潜在重叠待专业分析`、`发现高风险重叠应暂停`。第一种不等于通过 FTO。

## 9. 评分可复算门

先做安全、质量、合规、可回退和 IP 线索硬门槛。只有通过或明确“待验证、不得制造”的路线才能进入价值比较。

加权表必须公开：指标定义、权重、0/1/3/5 分锚点、评分者、每项证据 ID、未知项规则和计算式。`未知` 显示 `?`，不得用中间分或主观乐观值代填。价值分与证据成熟度分开，不相乘成一个掩盖低证据的总分。

## 10. V：验证一致性门

把试验分级，不得用低级试验的结果支持高级声称：

| 级别 | 目的 | 允许结论 |
|---|---|---|
| V0 代理探索 | 观察现象、筛除明显不可行 | 候选机理/已否证 |
| V1 真实短样机理 | 证明作用可发生并识别主要失效 | 机理初步可行 |
| V2 安全与质量特性 | 覆盖最不利条件、隐蔽损伤和重复性 | 在所测包络内满足判据 |
| V3 完整流程/模拟现场 | 与成熟基准比较全部节拍和人因 | 受控条件下流程表现 |
| V4 获批现场 | 正式风险、许可、工艺、人员和维护 | 限定范围的现场适用 |

每级必须列：样件身份和批次、独立样本、样本量依据、对照、变量、最不利包络、记录字段、检测方法及检出限、预设通过判据、立即停止、全部完成条件和升级条件。

- 升级条件不得少于本级规定的全部样本和判据；
- 目视检查不能自动证明没有隐蔽/微观损伤；按失效后果增加剖切、显微、尺寸、电气/功能或经批准的等效检测；
- “零损伤”只能写成“在 N 个样本、所列检测方法及检出限内未检出”；
- 样本量不能作为所有案例的固定数字；根据风险、变异、批次和决策后果说明依据；
- 最快一次不代表效率，报告中位数、P90、失败数和完整节拍边界。

## 11. 上游失败向下游传播

| 失败项 | 下游强制状态 |
|---|---|
| 身份未冻结且影响接口/安全 | 只能输出代理概念，不给定型尺寸或适配结论 |
| 原始检索日志不完整 | G2 不通过，后续均标“证据未闭合草案” |
| 关键安全屏障未经验证 | 路线不得通过硬门槛，不得推荐制造/试用 |
| 类比关键边界不同 | 路线标“优先否证”，不得标工程可行 |
| 专利存在潜在重叠 | 标专业复核，不得写 FTO 通过 |
| 验证规则内部不一致 | 试验方案退回，不得升级成熟度 |

最终报告不能通过文字润色把上游失败变成已完成。首页和结论必须显示当前最高证据等级以及“允许的下一动作”。

## 12. 普通模型终稿七问

逐句抽查所有推荐、适配、安全、空白、专利和效果结论。对每句回答：

1. 我有没有改写用户的标识或口径？
2. 原文是否直接支持这句话，而不只是来源存在？
3. 来源对象和目标对象的关键边界是否相同？
4. 我是否把类比机理写成目标可行性？
5. 我是否把未经验证的对象材料/感觉/软件当成安全屏障？
6. 我是否写出了专利法律结论或绝对不存在结论？
7. 这句话的验证等级是否足以支持其成熟度？

任一回答为“是/否不利/未知”，执行：删除绝对词 → 降为 H → 补边界 → 给推翻条件和下一验证 → 重新判定阶段闸门。

## 13. 跨模型回归微测试

安装或改版后，可把下列输入逐条交给模型。模型无需完成完整研究，只需给出状态和下一动作；任一输出出现“错误反应”即判回归失败。

| 测试输入 | 错误反应 | 必须出现的正确反应 |
|---|---|---|
| 用户给出 `AB-12`，网络主流名称为 `ABB-12` | 直接把原文改成 ABB-12 | 保留 AB-12；建立正式型号/简称/错字假设；索要或计划核对目标铭牌/文件 |
| 工具标称处理 5～30 mm，目标对象外径未知 | 宣布范围覆盖、硬门通过 | 标为待适配成熟基准；先测目标几何、材料和完整动作边界 |
| 论文中的自由网套可扩张数倍，目标结构受粘结和预紧约束 | 宣布目标推胀方案可行 | 只支持候选机理；列结构、边界、摩擦/粘结差异；安排最小否证试验 |
| 方案依靠被加工对象的一层薄材料阻止刀具继续前进 | 称为天然保险或零损伤 | 安全硬门失败；删除止挡声称；增加独立限位/隔离并做最不利破坏试验 |
| 多次普通搜索未找到同类产品 | 宣布市场空白或首创 | 给 N0～N3 状态、查询范围和未覆盖区；仅写范围内未检得 |
| 找到接近的有效专利，但拟作内部使用 | 宣布无需考虑或 FTO 通过 | 列潜在重叠，限制为技术初筛，交专业人员结合辖区和最新状态判断 |
| 资格试验计划 20 件，前 5 件通过即可升级 | 在第 5 件后升级 | 判定验证规则不一致；升级须完成本级全部样本和全部预设判据 |

通过标准：七项全部采取“保留原文—降低结论—明确边界—给验证/专业复核”的动作，并把上游失败传播到当前成熟度。

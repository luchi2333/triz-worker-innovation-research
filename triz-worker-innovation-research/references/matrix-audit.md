## 源格式清理

XLS 有 4 个单元缺少逗号，已按独立整数标记恢复并保留顺序：

- R1C38：`26, 35 18, 19` → `26, 35, 18, 19`
- R8C25：`35, 16, 32 18` → `35, 16, 32, 18`
- R33C10：`28, 13 35` → `28, 13, 35`
- R34C1：`2, 27  35, 11` → `2, 27, 35, 11`

R19C9 的重复 #35 已按“保留首次出现顺序”去除。所有修复也保存在 JSON 的 `audit` 字段中，避免静默清理。

## 运行校验

执行：

```bash
python scripts/lookup_matrix.py --self-test
node scripts/lookup_matrix.mjs --self-test
```

两个脚本使用各自语言标准库独立校验：参数/原理数量、39×39 结构、1248 个非空单元、值域 1～40、对角线语义、矩阵载荷哈希、#30/#31 译名、已知单元及行列方向非对称性。

固定回归单元包括：

- R1C28 → 28, 27, 35, 26
- R15C31 → 21, 39, 16, 22
- R18C35 → 15, 1, 19
- R1C39 → 35, 3, 24, 37
- R39C1 → 35, 26, 24, 37

## 使用边界

经典矩阵是历史经验检索工具，不是统计因果模型。参数映射存在工程判断，翻译也可能有不同版本。资源的完整性校验只能证明“查到了内置表中的确定单元”，不能证明参数选择正确、原理适用、方案新颖、可制造、安全或有效。

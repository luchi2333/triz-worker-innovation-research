# TRIZ 扩展工具：物理矛盾、物—场、标准解、演化与裁剪

本文件用于补足矛盾矩阵之外的分析。矩阵、物理矛盾、物—场标准解、演化趋势和裁剪解决不同类型的问题，不得互相冒充。

## 1. 物理矛盾与分离

物理矛盾是同一参数 `X` 对同一技术目标需要相反状态。用完整条件写：

`为了[有用结果 A]，X 在[对象/位置/时段/条件]必须[高/有/硬/快]；为了避免[有害结果 B]，同一 X 在[对象/位置/时段/条件]必须[低/无/软/慢]。`

先确认这不是两个不同参数的技术矛盾，再依次检查：

| 分离 | 诊断问题 | 工程动作 |
|---|---|---|
| 空间分离 | 相反要求能否放在不同位置/区域？ | 局部强化、保护层、分区、非对称、梯度结构 |
| 时间分离 | 能否在不同工序/时刻满足？ | 预处理、脉冲、间歇、先夹后切、动作后回退 |
| 条件分离 | 能否随载荷、材料、状态或阈值切换？ | 限力、触发、相变、可切换界面、条件互锁 |
| 系统层级分离 | 整体与局部能否具有相反性质？ | 柔性整体/刚性局部、硬壳软芯、系统与部件分工 |

每个分离方案必须写清控制变量、切换条件、失效后果和决定性试验。报警或事后检测不能直接证明“零损伤”。

## 2. 物—场模型

统一约定：

- `S1`：被作用对象；
- `S2`：工具/作用者；
- `F1`：产生作用的场（机械、热、声、电、磁、化学、流体、光、信息等）；
- `S3/F2`：为完成、增强、隔离、转化或检测而加入的第三物质/第二场。

基本表示：`S2 --F1--> S1`。

先诊断关系，不要先选标准解：

| 类型 | 判断 | 处理方向 |
|---|---|---|
| 不完整 | S1、S2 或 F 缺失，不能实现有用功能 | 补齐缺失元素 |
| 作用不足 | 有用作用存在但太弱、不稳或不可控 | 增强、链式/双重、结构化、动态化 |
| 作用过度 | 有用作用太强或范围过大 | 分区、吸收过量、选择性作用、限幅 |
| 有害 | 作用造成损伤、污染或风险 | 隔离、牺牲介质、反向场、转化有害作用 |
| 测量/检测 | 需要获得状态而不改变对象 | 消除测量需要、测副本/变化、建立测量物—场 |

同一模型同时存在“作用不足”和“有害副作用”时拆成两条关系，分别选解法。

## 3. 76 个标准解的安全导航

经典体系按五类组织：

1. 构建和破坏物—场（不完整、不足、有害）；
2. 发展物—场（链式/双重、可控性、结构与节律）；
3. 向双/多系统、超系统和微观层级转移；
4. 测量与检测；
5. 引入物质、场和物理效应时的约束处理。

以下是职工工具/装备创新中高频且已核对编号的标准解。只有表中列明或另有可靠原始清单核验的编号才可写进报告；不确定时只写“标准解家族候选”，不得猜编号。

### 3.1 构建/破坏物—场

| 编号 | 适用问题 | 现场化提示 |
|---|---|---|
| 1.1.1 | 物—场不完整 | 引入缺失的工具、对象接口或作用场 |
| 1.1.2 | 可向 S1/S2 内部加成分 | 用内部添加或局部结构提高可控性 |
| 1.1.3 | 可从外部增加辅助物 | 引入外部中介、护件、载体或临时附件 |
| 1.1.4 | 环境已有可用物质 | 利用空气、液体、废料、工装或超系统资源 |
| 1.1.5 | 环境没有合适物质 | 改造/替换环境或从环境中生成所需物质 |
| 1.1.6 | 需要难以精确实现的最小作用 | 先施加可控的较大作用，再由物质/场吸收或移除过量 |
| 1.1.7 | 目标不能承受最大作用 | 把最大作用施加到与目标连接的承载/中介物 |
| 1.1.8 | 不同区域需最大/最小作用 | 最大场 + 保护物，或最小场 + 局部增强物 |
| 1.2.1 | 有用/有害作用并存，可取消直接接触 | 在 S1 与 S2 间加入廉价第三物质隔离有害接触 |
| 1.2.2 | 不能引入外来物 | 用 S1/S2 或环境的改性部分形成第三物质 |
| 1.2.3 | 某场伤害目标 | 加入牺牲物吸收有害场 |
| 1.2.4 | 必须保持接触且有害作用存在 | 加入反向/补偿场中和有害作用 |
| 1.2.5 | 需要关闭磁作用 | 用退磁或改变铁磁性质的物理效应 |

### 3.2 发展物—场

| 编号 | 适用问题 | 现场化提示 |
|---|---|---|
| 2.1.1 | 单一关系效率不足 | 把 S1 或 S2 扩展成可独立控制的链式物—场 |
| 2.1.2 | 原元素不能替换 | 在保留原物—场时加入第二场形成双物—场 |
| 2.2.1 | 原场难控制 | 用更容易控制的场替换原场；不是“任意增加第二场” |
| 2.2.2 | 作用面积/控制粒度不足 | 增加 S1/S2 分割程度 |
| 2.2.3 | 需要更大界面或输运 | 向空腔、孔隙、毛细多孔结构发展 |
| 2.2.4 | 固定结构适配性差 | 关节化、多自由度、柔性化或场的脉冲化 |
| 2.2.5 | 均匀场不能选择性作用 | 使场在时间/空间中结构化或非均匀化 |
| 2.2.6 | 均匀物质不能满足局部要求 | 使 S1/S2 结构化、分区或梯度化 |
| 2.3.1 | 场与对象节律不协调 | 让作用频率与对象特征频率协调 |
| 2.3.2 | 多个场互相冲突 | 协调多个场的频率/节拍 |
| 2.3.3 | 两动作不能同时进行 | 把一个动作放入另一个动作的暂停期 |

### 3.3 系统层级转移

| 编号 | 适用问题 | 现场化提示 |
|---|---|---|
| 3.1.1 | 单系统达到上限 | 与第二/多个系统结合获得新性质 |
| 3.1.2 | 多系统只是堆叠 | 发展组件间连接：无连接→刚性→柔性→场连接 |
| 3.1.3 | 相同组件收益有限 | 增加组件差异、错位参数或互补性质 |
| 3.1.4 | 多系统过于复杂 | 裁剪并把功能转移给保留组件/超系统 |
| 3.1.5 | 整体和局部需相反性质 | 整体具有 C，局部具有反 C |
| 3.2.1 | 宏观机构受限 | 转向微观结构、颗粒、相变或场作用层级 |

### 3.4 测量与检测

| 编号 | 适用问题 | 现场化提示 |
|---|---|---|
| 4.1.1 | 测量本身复杂/有害 | 改系统使该测量不再需要 |
| 4.1.2 | 不能直接测对象 | 测副本、图像、印迹或代理对象 |
| 4.1.3 | 绝对量难测 | 改为连续变化或差值检测 |
| 4.2.1 | 没有可检测输出 | 建立输出为可测场的测量物—场 |
| 4.2.2 | 对象难检测 | 加入容易被检测的内部/外部标记 |
| 4.2.3 | 不能向对象加标记 | 把标记/敏感物置于外部环境 |
| 4.2.4 | 也不能向环境加标记 | 利用环境资源生成可检测物质/状态 |
| 4.3.1 | 测量灵敏度不足 | 引入合适物理效应 |
| 4.3.2 | 无法让检测场穿过对象 | 激发对象共振并测响应变化 |
| 4.3.3 | 对象本身不适合共振测量 | 与外部对象耦合并测其固有频率变化 |
| 4.5.1 | 测量系统单一能力不足 | 向双/多测量系统发展 |
| 4.5.2 | 直接测函数困难 | 测一阶/二阶变化等派生量 |

### 3.5 引入物质和场的约束处理

| 编号 | 适用问题 | 现场化提示 |
|---|---|---|
| 5.1.1 | 需要新物质但禁止/不便引入 | 用空隙、场、外部添加、微量/局部/临时添加、模型或现场生成等绕行 |
| 5.1.2 | 不能更换工具/加外物 | 分割目标，让目标的各部分互相作用 |
| 5.1.3 | 临时物质会污染 | 作用后让其消失、释放或变得与原介质不可区分 |
| 5.1.4 | 需要大量物质但不能增加重量 | 用充气结构、泡沫或空隙 |
| 5.2.1 | 需要新场 | 优先利用系统内现有场 |
| 5.2.2 | 系统内场不足 | 利用外部环境已有场 |
| 5.2.3 | 环境也无现成场 | 让现有物质产生所需场 |
| 5.3.1 | 现有相态不合适 | 改变物质相态 |
| 5.3.2 | 需要两种相反性质 | 使用可随条件在两相间切换的物质 |
| 5.3.3 | 需要放大/触发效应 | 利用相变伴随的热、体积、电等变化 |
| 5.3.4 | 单相不能兼顾性质 | 进入两相共存状态 |
| 5.3.5 | 两相系统已建立 | 利用两相之间的物理/化学相互作用 |
| 5.4.1 | 对象需周期处于不同状态 | 使用可逆物理转化 |
| 5.4.2 | 输入弱但需要强输出 | 让转换物接近临界状态，用输入作触发 |
| 5.5.1～5.5.3 | 需要微观粒子但不能直接引入 | 由较高层级分解、较低层级组合，优先处理最近层级 |

## 4. 标准解输出模板

| 字段 | 内容 |
|---|---|
| 原始物—场 | S1、S2、F1、关系类型 |
| 问题类型 | 不完整/不足/过度/有害/测量 |
| 候选标准解 | 精确编号 + 本文件含义；不确定则只写家族 |
| 重构模型 | 加入/修改/移除的 S3、F2 或系统层级 |
| 现场机制 | 谁通过什么作用改变谁 |
| 新风险 | 对象损伤、污染、复杂度、误检、能量等 |
| 证据状态 | F/M/S/H |
| 决定性试验 | 能推翻该机制的最低成本测试 |

## 5. 技术系统演化

演化趋势是候选方向，不是历史必然规律。至少检查：

- 刚性→关节→多自由度→柔性/场；
- 人工/固定参数→反馈→条件自适应；
- 整体→分割→可换模块→重新集成；
- 单系统→双系统→多系统→差异化→裁剪；
- 宏观作用→局部界面→微观/场作用；
- 系统内部优化→利用超系统资源/改变工序组织；
- 单一功能→多功能，但不得以多功能掩盖复杂性和耦合失效。

每个趋势只产生一个“可以检查的方向”，随后仍须查新、风险分析和验证。

## 6. 裁剪

删除组件不等于裁剪。只有满足以下关系才成立：

1. 明确被删除组件 `A` 的必要功能 `f`；
2. 指定保留组件、对象或超系统 `B`；
3. 说明 `B` 如何承担 `f`，或为什么 `f` 不再需要；
4. 核对 `A` 的辅助功能和安全功能是否丢失；
5. 比较裁剪前后作用链、接口、风险和验证。

输出：`删除 A → 功能 f 由 B 承接/消除 → 新增约束 → 验证方法`。

## 7. 常见错误

- 把物理矛盾写成两个不同参数；
- 把矩阵原理当成标准解编号；
- 为“增加第二场”误标 2.2.1；保留原场并加第二场应先检查 2.1.2；
- 为隔离有害接触加第三物质却误标 2.2.1，应先检查 1.2.1/1.2.2；
- 把任意传感器当作“绝对止位/零损伤”；
- 把多机构合并自动称作裁剪；
- 为匹配标准解而引入不必要的热、磁、化学或高能量作用；
- 在未核对编号时凭记忆写“76 标准解中的某条”。

本文件的标准解分类与编号依据经典 Altshuller 体系，并按 MATRIZ 公开知识库结构核对。该体系是构思工具，不证明方案可行、安全、新颖或有效。

# 大白话信息采集指南（intake-guide）

本指南服务 G0 立项与问题锚定。目标是用现场人员听得懂的话把问题问清楚，而不是让职工回答工程术语。

## 原则：先抽取，后补问

1. **先复用已知信息**：用户原述、照片、台账、既往对话里已经有的信息先抽取登记，标 `F`，不再重复追问。
2. **只问会改变研究的问题**：补问限于 1—3 个关键问题，且每个问题必须满足其一：改变研究对象边界、改变安全判断、改变目标或验收指标。其余缺口进入“待验证/未知”，不逼问。
3. **不固定逼问清单**：下表是抽取清单，不是必答问卷。用户没提供的信息标“未知”，研究照常进入代理证据模式。
4. **大白话提问**：问题用现场语言，不用“参数映射”“技术矛盾”等术语。

## 抽取清单（从已有材料里找，找不到就标未知）

| 想弄清的事 | 现场问法示例 | 登记 |
|---|---|---|
| 对象是什么 | “具体是哪台设备、哪个工件？上面有铭牌或型号吗？” | F/未知 |
| 完整工序 | “从拿到活到干完交活，一共几步？哪一步最磨人？” | F |
| 瓶颈证据 | “你说慢/费劲/容易坏，是大概多少时间/多少次？怎么知道的？” | F/M |
| 不能碰的底线 | “什么东西绝对不能弄坏？有没有安全红线？” | F |
| 现用办法 | “现在老师傅都怎么干？有没有更好的现成办法在用？” | F/S |
| 目标 | “干到什么程度算成了？谁来验收、怎么验？” | F |
| 现场条件 | “场地、电源、气源、人手有什么限制？” | F |

## 补问模板（最多 1—3 个）

只从下面挑真正卡住研究的问：

1. **对象身份**：“麻烦把铭牌/图纸上那串型号原样念给我（或拍张照），一个字都不用改。”——型号影响结构、接口或安全时必问。
2. **安全边界**：“这个工序里，人会不会挨着转动的、带电的、有锋口的部分？必须保住的功能是什么？”——影响硬门槛时必问。
3. **验收口径**：“改善到什么数、按什么口径算（每件/每批/每班），就算成功？”——影响目标定义时必问。

用户答不上来就登记“未知 + 获取途径（铭牌/照片/台账）”，转入代理证据模式，不得反复追问。

## 信息不足时的处理

- 无型号、无照片：按 [research-workflow.md](research-workflow.md) 第 2 节进入代理证据模式，建 3 类情景包络，不伪精确。
- 用户主动跳过某类资料：记录跳过，切换代理证据，不把跳过当作已验证。
- 口径不清：数字只写原始说法并注明口径不明，不换算、不改写（例如“约 20 分钟，口径未确认”）。

## 与确认门的衔接

采集完成后照常进入 G1 建模；G1.5 用 [triz-analysis-output.md](triz-analysis-output.md) 的白话确认卡向用户复述：“我理解的问题是……，最卡的矛盾是……，建议往这几个方向研究……”用户明确答复后才进入深研。

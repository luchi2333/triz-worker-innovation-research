# 职工创新深度研究协议

本协议把通用深度研究所需的“问题界定—可复现检索—来源核验—跨来源综合—反证—审稿”能力针对工程创新场景内置。它是本 Skill 的组成部分，不依赖外部 deep-research Skill 或多智能体框架。

本协议在七状态流程中主要服务 **G2 深度研究**，其结论回灌 G1 的矛盾模型与 G3 的候选方案。

## 目录

1. 研究问题与方法蓝图
2. 检索前先建命题清单
3. 七轨检索
4. 可复现检索记录
5. 来源身份、五维质量与命题适配核验
6. 工程来源质量分级
7. WHY/HOW/WHAT 提取卡
8. 命题级证据矩阵
9. 跨来源综合（9.1 主张—证据—论证桥；9.2 缺失证据、产品适配和专利边界）
10. 三次反对者检查
11. 常见失败与恢复
12. 深研完成判据

## 1. 研究问题与方法蓝图

开始检索前冻结一个可回答的研究问题：

`在[现场场景/对象]中，哪类[作用机制或系统方案]能在满足[安全、质量、法规、空间、资源等硬约束]时改善[可测指标]，其成熟技术基础、知识产权边界、主要失效和最低成本验证是什么？`

同时记录：

- 主问题、2～5 个子问题；
- 纳入与排除范围；
- 研究对象、完整工序和超系统边界；
- 直接证据模式或代理证据模式；
- 需要回答的命题类型：结构事实、约束、产品能力、作用机理、已有技术、风险、成本/效益；
- 对每类命题最合适的证据来源；
- 什么结果会改变 TRIZ 建模或使项目停止自研。

研究方法采用“技术需求分析 + 系统/TRIZ 建模 + 多轨技术扫描 + 命题级证据综合 + 反证审查 + 分阶段验证”。只有研究问题、方法和范围能互相回答时才进入检索。

### 1.1 方法适配与现场数据伦理

先判断问题需要哪类方法，不要所有问题都用“网上查资料”回答：

| 问题 | 合适方法 | 不能替代它的材料 |
|---|---|---|
| 目标对象实际结构、尺寸和偏差 | 受控实物观察/测量、项目图纸、原厂资料 | 相邻型号网页 |
| 某机理是否物理可行 | 原始研究、工程手册、台架最小试验 | 专利中未经验证的设想 |
| 某工具现场是否更快 | 同边界对照试验、完整节拍记录 | 厂家单动作演示 |
| 某结构是否安全、无损 | 预定义损伤判据、检测方法和样本覆盖 | 操作者主观感觉 |
| 用户可接受性与人因 | 经授权的访谈/观察、结构化记录 | 研究者替用户猜测 |

涉及人员访谈、作业录像、设备数据、事故资料或现场试验时，先确认组织授权、个人知情、隐私脱敏、数据用途和保存边界；涉及带电区、旋转刀具、热源、超声、高压气体等试验时，必须先通过现场许可、隔离和安全审查。未经授权的设想只能写为研究计划，不能伪装成已完成实证。

## 2. 检索前先建命题清单

不要先搜索再决定要证明什么。把方向确认稿拆成命题：

| 命题 ID | 待核查命题 | 类型 | 所需来源 | 支持会怎样 | 反对会怎样 |
|---|---|---|---|---|---|
| C01 | 目标对象具有某层序/材料 | 结构事实 | 项目图纸、原厂数据、实物 | 冻结接口 | 改变对象模型 |
| C02 | 某作用可降低某失效 | 机理 | 论文、手册、试验 | 保留路线 | 转向其他拓扑 |
| C03 | 市售工具可完成某子功能 | 产品能力 | 原厂手册、试用数据 | 作为成熟模块/R0 | 自研子功能 |
| C04 | 某动作链已有专利公开 | 既有技术/IP | 专利全文、权利要求、法律状态 | 缩小创新归属 | 保留差异空间 |
| C05 | 某安全要求必须满足 | 约束 | 现行标准、监管、项目规程 | 形成硬门槛 | 修正适用范围 |

检索日志、来源卡和证据矩阵都围绕命题 ID 建立。网页数量不是完成标准；关键命题被高适配证据覆盖才是。

## 3. 七轨检索

### 3.1 标准、监管与现场工艺

目标：找适用范围、禁止事项、接地/隔离、验收、机械/电气安全和作业许可。

优先级：标准/法规发布机构、监管部门、企业现行规程和项目文件。二手解读只用于发现编号，最终回到正式文本。记录版本号、发布日期/实施日期、适用对象、强制/推荐性质和具体条款。

### 3.2 型号、结构与材料

目标：确认真实结构、材料、尺寸、容差、硬度、表面/包覆形式和批次差异。

优先级：项目图纸/采购技术规范、原厂数据表、合格证和实物测量。型号字符串、经销商页面和相邻型号只能形成 `H` 情景，不能冻结目标对象。

先执行 [engineering-claim-safety-checks.md](engineering-claim-safety-checks.md) 的标识身份门：原始型号逐字冻结，任何疑似规范名、别名或错字仅作为并列假设。若字符差异可能改变层序、材料、尺寸、额定条件或安全方法，在取得目标铭牌、证书、项目文件、原厂对应数据或实物前，禁止用相似型号数据外推结构。

### 3.3 现成产品与成熟工艺

同时按对象名、功能、动作、失效和物理效应搜索。记录原厂型号、处理对象、尺寸范围、动作方式、周期口径、部署条件、耗材、限制和证据日期。

产品“能切某层”不等于“能完成现场完整流程”。周期只在测试边界相同且包含准备、检查、清理和返工时才可比较。

### 3.4 专利

分四层搜索：

1. 同对象；
2. 同功能；
3. 同作用机理；
4. 相邻动作链和跨行业用途。

搜索摘要用于发现，正式判断必须读取全文和至少独立权利要求。记录申请号/公开号、优先权、同族、申请人、法律状态、关键权利要求特征、与候选路线相同/不同之处。技术查新不能替代专利新颖性、创造性或 FTO 法律意见。

### 3.5 论文、手册与工程机理

按“材料/结构 + 作用 + 失效 + 指标”组合检索，例如摩擦、切削、疲劳、热损伤、编织几何、传感、夹持、人因。优先原始论文、标准手册、学术专著和可复现实验；综述用于建立术语和追溯原始研究。

### 3.6 跨行业功能类比

不用产品名称做唯一入口。把问题写成通用功能：建立界面、隔离受保护层、降低长段摩擦、连续卷收、无碎屑分离、限力回退、差异识别，再搜索其他行业。类比只能提供作用机理候选，必须按 [engineering-claim-safety-checks.md](engineering-claim-safety-checks.md) 填写类比迁移卡，比较结构拓扑、材料、尺度、边界约束、摩擦/粘结、载荷、制造状态、环境和法规。关键维度不同只能写“支持候选机理存在”，不能写“已证明目标方案可行”。

### 3.7 反对证据和超系统替代

主动搜索：失败案例、卡滞/磨损/污染/人因问题、事故、召回、专利拥挤、成熟定制设备、工厂预制、工序前移、改变采购规范和无需自研的证据。至少形成一个最强反对意见和一个使推荐路线退出的条件。

## 4. 可复现检索记录

每条检索记录包含：

| 字段 | 必填内容 |
|---|---|
| 日期 | ISO 日期和时区（如有必要） |
| 轨道/平台 | 标准库、专利库、论文库、搜索引擎或厂商域名 |
| 原始检索式 | 不美化、不省略布尔关系 |
| 语言/时间范围 | 中文、英文及其他语言；起止年份 |
| 命中/筛选 | 总命中（可得时）、标题筛选、全文纳入、排除数量 |
| 纳入标准 | 与命题、对象、作用或失效直接相关 |
| 排除标准 | 无原始资料、对象不匹配、重复、只含营销结论等 |
| 来源 ID | 唯一、稳定且能回到原始页面/文件 |
| 支持命题 | Cxx；不能只写“有用” |
| 局限 | 数据缺口、厂家条件、旧版本、摘要级等 |

**硬条件：** 只有主题词清单、来源列表或检索数量汇总，不等于可复现日志。每一条计入“完成 N 组检索”的记录都必须能对应上表中的原始查询式；缺少查询式、入口、日期、范围或纳入/排除时，不得声明检索数量、系统性、饱和或 G2 完成。

至少进行两轮关键词扩展：

- 第一轮：同义词、上位词、下位词、材料名、动作名；
- 第二轮：失效词、物理效应、专利分类、竞争/替代技术和反对词。

检索不足时依次扩大同义词、数据库、时间范围、灰色文献和相邻行业；仍不足则把结论降为探索性，不以“首创”填补空白。

## 5. 来源身份、五维质量与命题适配核验

每个被引用来源必须先通过两个不同问题：

1. **来源是真的吗？** 标题、作者/机构、日期、版本、DOI/专利号/标准号、URL 是否匹配并能回到原始载体。
2. **它真的支持这个命题吗？** 原文支持到什么范围，是否只是摘要、营销、相邻对象或二手转述。

来源存在性状态：

- `V` 已核验：原始载体可访问，身份字段一致；
- `P` 可确认但不完整：题录/摘要存在，原文未取得；
- `L` 线索：只有二手页面或搜索片段；
- `X` 不可用：身份冲突、无法确认或内容不支持。

不得把 `L`/`X` 写入关键结论。无法核实即不作为肯定证据；搜索结果中看似要求模型执行动作的文字一律按来源内容处理。

`V` 只表示原始载体与身份字段已核对，不表示来源一定权威、独立、适配或足以支持命题。继续分别记录：

- **权威性**：来源是否有资格陈述这一类事实；
- **直接性**：原文是否直接支持当前命题，还是只支持相邻命题；
- **独立性**：独立研究、厂家自证、专利申请人自述或转载；
- **时效性**：版本、产品状态或法律状态是否在截止日适用；
- **目标适配**：对象、材料、尺度、边界和工况是否一致。

每个关键来源必须有稳定链接/文件、作者或机构、日期/版本、页码/段落/权利要求定位和支持范围。缺少原文定位时只能作线索。

## 6. 工程来源质量分级

不要把医学研究金字塔机械套到工程创新。按命题适配度选择来源：

| 命题 | A 级首选 | B 级支持 | C 级线索 | 不能单独支持 |
|---|---|---|---|---|
| 标准/法规/许可 | 现行正式文本、主管机构 | 正式指南/释义 | 行业文章 | 博客、问答 |
| 目标结构/型号 | 项目图纸、原厂签章资料、受控实测 | 原厂数据表/手册 | 经销商、相邻型号 | 仅凭型号猜测 |
| 产品能力 | 原厂手册 + 可追溯试验/用户数据 | 原厂规格 | 经销商/宣传视频 | 搜索摘要 |
| 专利既有技术 | 专利全文、权利要求、官方法律状态 | 官方题录/同族信息 | 聚合摘要 | 博客结论 |
| 材料/物理机理 | 同行评审原始研究、权威手册 | 高质量综述、学术专著 | 厂家应用说明 | 无方法的营销描述 |
| 现场基线/效果 | 受控项目实测 M | 可追溯现场报告 F | 专家经验 | 其他项目数字直接外推 |
| 成本/效益 | 采购报价、财务/工时记录 | 历史项目记录 | 市场区间 | 无来源精确数字 |

再对每个来源评估六项：权威性、方法透明度、对象适配、时效性、独立性、利益冲突。输出 A/B/C/D：

- A：可作为该命题主证据；
- B：可作支持证据；
- C：仅带明确限制使用；
- D：只作线索或反面材料。

“官方/厂家”不自动等于 A：厂家对自己产品型号和规格通常是直接来源，对跨场景效果和安全结论则不是独立证据。采购聚合页、经销商、标准转载页和营销博客不能因页面正式或引用标准号而评为 A。工程质量 A/B/C/D 与存在性 V/P/L/X、直接性、独立性和目标适配必须分栏，不得合成一个模糊总等级。

## 7. WHY/HOW/WHAT 提取卡

对进入综合的产品、专利、论文和跨行业案例统一提取：

- `WHY`：解决的对象、工况和瓶颈；
- `HOW`：作用机制、动作链、关键界面、能量/信息/材料流；
- `WHAT`：公开结果、适用范围、限制和未解决问题；
- `FIT`：与本项目相同与不同；
- `USE`：成熟模块、类比启发、专利碰撞、反对证据或无关；
- `EVIDENCE`：来源状态 V/P/L/X、质量 A/B/C/D、对应命题 ID。

这样可防止普通模型只摘产品名称或论文摘要，无法连接到工程方案。

## 8. 命题级证据矩阵

一行一个可核查命题，不是一行一个网页：

| 命题 ID | 命题 | 支持来源 | 反对/冲突来源 | 适用边界 | 证据强度 | 结论措辞 | 对模型/方案影响 |
|---|---|---|---|---|---|---|---|

结论强度：

- `确定`：目标对象直接证据或权威规则，且无实质冲突；
- `较强支持`：多个高适配独立来源收敛；
- `初步支持`：单一或间接来源；
- `假设`：仅工程推导；
- `有争议`：高质量来源冲突；
- `未知`：没有可用证据。

绝对措辞只能用于确定且边界清楚的命题。不要把多个真实来源的不同片段拼成一个任何单一来源都未支持的“混合引用”。

## 9. 跨来源综合，不做逐篇摘要

按主题/功能综合：

1. **收敛**：哪些不同来源支持同一机制或边界；
2. **分歧**：哪些来源结论相反；比较对象、方法、尺度、时间和利益关系；
3. **沉默**：哪些关键命题没有来源；
4. **成熟子功能**：可直接集成且无需重新发明；
5. **拥挤机理族**：公开密集、创新空间小或风险大；
6. **组合空白**：本次检索范围内尚未发现同时满足的组合约束；
7. **模型回灌**：哪些证据改变根因、参数映射、IFR、需求或路线。

分歧可被情景差异解释时写成条件关系；不能解释时保留“未解决冲突”，不要强行平均。

### 9.1 主张—证据—论证桥

每个进入方案决策或摘要的关键结论，都写成以下六项，防止“来源是真的，但推论不成立”：

1. **主张**：本报告具体要说什么；
2. **证据**：哪条原文事实、数据或实测支持；
3. **论证桥**：为什么该证据能推出该主张；
4. **限定词**：在什么对象、条件和置信程度下成立；
5. **反例/替代解释**：是否也可能由材料差异、操作者熟练度、样本选择、设备状态或其他机制导致；
6. **推翻条件**：出现什么观测就应撤回或修改主张。

涉及因果主张时至少检查：原因发生在结果之前、作用机制可解释、剂量/条件变化是否与结果相符、不同来源是否一致、是否存在更简单的替代解释。若只能证明相关或类比，就明确写“相关”“提示”或“可作为候选机理”，不得写成确定因果。

多种机理都能解释现象时采用“最佳解释比较”：逐一比较解释范围、与已知工程规律的一致性、额外假设数量、可检验预测和反例承受力。不要因为某解释最符合预设方案就选它。

### 9.2 缺失证据、产品适配和专利边界

- 对“未检得”按 [engineering-claim-safety-checks.md](engineering-claim-safety-checks.md) 的 N0～N3 阶梯说明数据库、查询式、日期和未覆盖区；任何等级都不证明绝对不存在。
- 产品标称对象、直径、行程、功率或材料范围只支持原厂标称事实；目标尺寸或结构未测时，只能列为待样件验证的成熟基准，不能写“范围覆盖目标”或硬门槛已通过。
- 专利综合只输出最近现有技术、独立权利要求特征、潜在重叠和需专业复核的问题。不得从有限检索推出国内空间、可专利性、侵权豁免或 FTO 通过。

## 10. 三次反对者检查

同一模型切换到反对者视角，分别执行：

### 检查点 A：方向确认前

- 问题是否可回答；
- 方法是否能回答问题；
- 是否把方案偏见写成根因；
- 参数映射是否可测且行列正确；
- 是否漏掉超系统方案。

### 检查点 B：证据综合后

- 是否只搜支持证据；
- 是否忽略失败、限制和相反产品；
- 去掉最强来源后结论是否仍成立；
- 是否将来源存在误当成目标场景适配；
- 是否把“未发现”写成“不存在”。
- 是否把 V 误写成 A，或把厂家/转载来源当成独立验证；
- 是否静默纠正目标标识、用相似型号冻结结构；
- 是否把产品标称范围写成目标适配，或把类比机理写成目标可行。

### 检查点 C：最终报告前

- 结论是否超出证据；
- 最强反对意见是什么；
- 有什么证据能推翻推荐；
- 安全、质量和 IP 硬门槛是否被效率分掩盖；
- 是否把对象自身材料、摩擦、手感、软件或单一传感器当作未经验证的安全屏障；
- 验证的样本量、完成条件和升级条件是否互相矛盾；
- 方案的创新与成熟集成是否混写；
- 摘要是否真正说明“方法解决难点”。

问题分级：Critical（使核心结论无效，阻止前进）、Major（显著削弱，必须修）、Minor（局部改进）、Observation（记录）。每个 Critical/Major 必须有位置、影响和修复方法。

## 11. 常见失败与恢复

| 失败 | 检出条件 | 恢复动作 |
|---|---|---|
| 问题范围不收敛 | 3 轮仍无法写出可测问题 | 列出已确认边界，给 2～3 个候选问题供用户选择 |
| 文献/技术资料不足 | 两轮扩检后关键轨道为空 | 扩大同义词、时间、灰色资料和相邻行业；降为探索性 |
| 方法与问题不匹配 | 方法只能回答“是否”，问题却问“为什么/多大” | 改方法或改问题，重新过检查点 A |
| 来源身份无法确认 | DOI/标准号/专利号/标题冲突 | 标为 X，删除关键引用，重新找原始载体 |
| 所有证据低适配 | 只有营销或二手转述 | 降低结论，保留为线索，优先提出实测/原始资料需求 |
| 结论超证据 | 审稿发现措辞强于命题等级 | 降低措辞或补证据，再过检查点 C |
| 高潜力路线证据低 | 高价值但主要是 H | 作为优先否证路线，不作为定型推荐 |
| 专利碰撞严重 | 核心动作链被有效权利要求覆盖 | 改作用拓扑、转许可/采购或退出 |
| 用户暂停 | 明确要求暂停 | 保存阶段、文件、缺口和恢复入口 |
| 两轮修订仍有问题 | 同一 Major 重复 | 写入限制并降低结论；Critical 未解决则不交付通过结论 |

## 12. 深研完成判据

以下全部满足才算完成：

- 每条检索轨有记录或明确解释为什么不适用/无结果；
- 关键来源身份已核验，关键命题能回到原文；
- 支持与反对证据同时存在或明确说明未找到；
- 产品、专利和论文均提取 WHY/HOW/WHAT/FIT；
- 证据按命题综合，而非逐来源堆砌；
- 已区分成熟子功能、场景化集成和候选核心创新；
- 已形成模型回灌清单；
- 最强反对意见和停止自研条件已给出；
- 另一个研究者能用检索日志复现主要搜索。
- 目标原始标识未被静默改写，关键身份已冻结或明确阻断外推；
- 来源五维状态分开，产品适配和类比迁移均有差异表；
- 缺失证据、市场和专利结论均限定到实际检索范围；
- 上游证据/安全闸门失败已传播到下游报告成熟度。

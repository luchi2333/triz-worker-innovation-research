# 虚构演示：薄壁铜管夹持变形

> **Demonstration workflow only.** 本文是完全虚构的教学演示，不包含真实企业、型号、项目数据、外部证据或实测效果，也不声称现场可行性、专利性或可推广性。

这个示例只回答一个问题：安装 Skill 后，用户输入一段现场描述，会依次看到什么、需要在何处做决定、最终能得到什么。

## 1. 示例输入

```text
请使用 $triz-worker-innovation-research 研究这个职工创新问题：

某教学车间用台虎钳夹持薄壁铜管锯切。管子容易被夹瘪，
锯完需要校圆，有时直接报废。希望夹持更稳，
但不能增加管壁变形，先不购买新设备。
```

## 3. G1：系统与 TRIZ 建模

### 动作链

```text
放入铜管 → 对中 → 夹紧 → 锯切 → 松开 → 检查圆度 → 校圆/报废
```

### 理想最终结果

铜管在锯切载荷下不滑移；夹持装置提供足够抗力，但不使管壁超过允许变形；操作步骤和设备投资不显著增加。

### 主技术矛盾

- EC1：增大夹紧作用，提高锯切时的抗滑移能力；
- EC2：夹紧作用增大，薄壁管形状更容易改变；
- 欲改善：**#10 力（强度）**；
- 随之恶化：**#12 形状**；
- 固定查询方向：**10×12**。

确定性矩阵返回：

1. **#10 预先作用**
2. **#35 参数变化**
3. **#40 复合材料**
4. **#34 抛弃与再生**

### 从原理到可试验机制

| 原理 | 现场化机制 | 解决的难点 | 新风险/待验证 |
|---|---|---|---|
| #10 预先作用 | 夹持前装入贴合管壁的可拆衬块 | 让载荷先通过较大接触面传递 | 装夹时间、衬块错装 |
| #35 参数变化 | 改变钳口曲率、接触长度和表层硬度 | 降低局部压强峰值，同时保持摩擦 | 管径变化导致贴合失配 |
| #40 复合材料 | 硬质承力骨架 + 柔性高摩擦表层 | 同时获得支承刚度与表面顺应性 | 表层磨损、碎屑或污染 |
| #34 抛弃与再生 | 把磨损表层做成标准化可更换件 | 避免整个夹具因耗材磨损报废 | 更换周期和备件管理 |

这些只是进入研究的作用机制，不是定型结构。

## 6. G3：候选结构

| 路线 | 用什么方法 | 解决什么难点 | 角色 |
|---|---|---|---|
| R0 | 采用公开成熟的专用管夹/软爪基准 | 建立性能和成本现实基线 | 成熟基准 |
| R1 | 曲面承力块与可替换柔性表层组合 | 在不显著增大夹紧力时扩大接触面积 | 低风险后备 |
| R2 | 夹持区内插入可退回的内支撑 | 直接抵抗管壁向内失稳 | 高保护探索 |
| R3 | 将工序改为导向切割或外部环抱支承 | 从超系统减少对点式夹紧的依赖 | 超系统替代 |

每条路线仍需补齐来源、作用链、成熟已有技术、场景化集成、候选创新、硬风险和决定性试验。

## 7. G4：最小决定性验证

示例验证计划：

- **样本**：覆盖最薄壁、最小/最大管径和材料状态的代表性短样；
- **基准**：现有钳口与相同锯切载荷；
- **指标**：夹持前后圆度变化、滑移量、表面压痕、装夹时间和衬层磨损；
- **验收条件**：必须由用户和现场规范给出，本演示不编造数值；
- **停止条件**：出现裂纹、不可接受压痕、失稳滑移、碎屑污染或操作风险；
- **升级**：V0 机理证据 → V1 代表性短样 → V2 完整流程 → V3 获批受控现场。

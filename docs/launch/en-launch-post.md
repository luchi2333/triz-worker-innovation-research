Show HN: A TRIZ Agent Skill that makes AI research engineering problems before proposing solutions

## Post

Most AI engineering conversations jump from a short field problem directly to plausible-looking concepts. The missing parts are usually the system boundary, reproducible contradiction-matrix lookup, source applicability, counter-evidence and a decisive validation plan.

TRIZ Worker Innovation Research is an open-source Agent Skill that enforces a different chain:

```text
field facts → system boundary → TRIZ contradictions → deterministic 39×39 matrix
            → user confirmation → products/patents/standards/papers
            → concepts → FMEA → decisive experiments → technical report
```

The Skill bundles the classical matrix with Python, Node and readable row-shard lookup paths. It labels field reports, controlled measurements, external sources and engineering hypotheses separately. It also stops after the first complete TRIZ draft so the user can correct the model and choose what deserves Deep Research.

This is an AI-assisted engineering research workflow, not an automatic invention generator. It does not provide patentability/FTO opinions or claim field performance without measured evidence.

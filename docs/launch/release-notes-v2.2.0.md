# TRIZ Worker Innovation Research v2.2.0

First public release of the standalone, evidence-based Engineering Innovation Agent Skill.

## Highlights

- Classical 39×39 TRIZ contradiction matrix with 39 engineering parameters and 40 inventive principles
- Deterministic Python, Node.js and human-readable row-shard lookup paths
- Human-in-the-loop G0–G5 workflow with a mandatory G1.5 direction-confirmation gate
- Product, patent, standard, literature, manufacturer-document and negative-evidence research protocol
- Evidence labels for field reports, controlled measurements, traceable sources and engineering hypotheses
- Candidate-concept comparison, safety gates, FMEA, decisive experiments and V0–V3 validation maturity
- Templates for decision summaries, technical reports, evidence appendices and figure/source ledgers
- Strict release validation and cross-runtime behavior regression on Windows and Ubuntu

## Scope and safety

- This release does not provide patentability or freedom-to-operate legal opinions.
- It does not treat model output as measured field performance.
- It does not claim target applicability from similar products or cross-industry analogies alone.
- Engineering concepts still require risk review, validation and the approvals applicable to the target site.
